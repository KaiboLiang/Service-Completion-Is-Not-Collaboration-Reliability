# Data and experimental results

Materials for *Service Completion Is Not Collaboration Reliability: Automation Procurement with Complementary Recovery Capacity*.

- `data/`: synthetic center and support states, task definitions, capability catalogue, and model and generator parameters.
- `results/`: package comparisons, price trajectories, sensitivity and held-out results, and cooperative-record aggregates reported in the paper.

The baseline has 48 center states, 115 support states, 325 packages, and Wasserstein radius 0.66818. Costs use normalized units. Variable definitions and experiment specifications are given in the manuscript and E-Companion.
